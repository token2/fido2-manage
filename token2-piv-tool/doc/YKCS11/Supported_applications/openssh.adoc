== OpenSSH

Keys stored on the Token2 key can be used to login to remote SSH servers. This can be done either with the Token2 key's PIV application using, for example, OpenSSH, or with the Token2 key's PGP application.

Following are some command line examples of using OpenSSH with the Yubikey's PIV application through T2CS11. For guides on how to use the YubiKey's PGP application for SSH authentication, see https://developers.yubico.com/PGP/SSH_authentication/[here] 

To direct OpenSSH to use key's stored on the Token2 key, the T2CS11 module needs to be specified with the `-I` option in the command line

[source, bash]
----
$ ssh -I /path/to/libt2cs11.so git@github.com 
----

To download the public key accessible through the T2CS11 module: 

[source, bash]
----
$ ssh-keygen -D /path/to/libt2cs11.so 
----
