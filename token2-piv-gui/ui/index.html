Factory reset FIDO2

All passkeys, fingerprints and the PIN will be erased. A key only accepts a reset shortly after power-up, so this is done step by step.

  1. Remove the key now — unplug it, or lift it off the NFC reader.
  2. Insert it again — plug it back in, or tap it on the reader and hold it there.
  3. Resetting… touch the key when it blinks (for NFC, keep it on the reader).
  4. Done.

    Button HOTP (typed as keystrokes)

    A separate HOTP secret the key types when its button is pressed outside any session. Leave the secret empty to change only the options.

    Set OTP PIN

    Protects the stored accounts: codes are only readable after the PIN is verified. Numeric PINs need 6+ digits (no sequences, repeats or palindromes); alphanumeric ones 10+ characters with two character classes. 100 attempts before lock-out.

    USB interfaces

    Only the keyboard interface (HOTP typed as keystrokes) can be switched here. FIDO and the smart-card interface are shown for information and stay as they are — disabling them could leave the key unreachable.

    The key re-enumerates on USB after the change; reconnect afterwards.

    Set applet password

    Required to list or use accounts. Unlike a PIN, wrong attempts are not counted.
